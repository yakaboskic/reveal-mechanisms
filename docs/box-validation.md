# Box / Claude / selected-graph validation

Workstream C owns `agent_execution.py`, `box_*.py`, the paragraph skill,
`agent-runtime/box-requirements.txt`, standalone scripts and transport tests.
Backend acceptance alone can publish an account. A successful Box result is raw

## Execution boundary

`BoxExecutionAdapter(project_root).execute(request, emit, cancelled, checkpoint)`
is asynchronous. The frozen `ExecutionRequest` binds job/attempt, research or
paragraph kind, input path, local output directory, selected graphs, timeout,
maximum turns and dollar budget. `checkpoint(dict)` must durably fence updates
under the current worker lease. `ExecutionResult` returns raw per-account files,
paragraph segments, trusted runtime manifest and complete tool ledger paths.

The worker assigns ordered persisted JobEvents. Public transport events are
`agent_started`, `agent_message`, `tool_call`, `tool_result`, `warning` and
`agent_completed`. Only text blocks and observable tool summaries are emitted;
Claude thinking/signature blocks remain private. The remote event cursor is
checkpointed after durable callback delivery, so recovery is at least once.
Worker persistence should deduplicate cursor replay if exact-once display is
required; the integrated worker now persists the stream/sequence deduplication
key. Browser disconnect does not cancel remote work.

Remote handles bind Box ID, job/attempt, creation timestamp, phase and event
cursor. Reconnection reuses the Box. A remote lock/status guard prevents duplicate
Claude launch after an uncertain response. Interrupted preparation requires a
new attempt and cleans up its prior Box. Terminal Boxes are deleted after output
capture; a collection or transport failure retains its handle for recovery.
Cancellation writes a trusted marker; the runner terminates the whole Claude
process group and marks unfinished calls interrupted. The remote deadline also
bounds execution if the worker disconnects. Delete failures emit an explicit
cleanup warning, raise a recoverable transport error, and retain the checkpoint
for operational cleanup.

## Isolation and policy

Each fresh attempt uploads an explicit bundle allowlist and immutable source
artifacts verified by SHA-256. No repository environment file, unrelated source
or local credentials are uploaded. The worker transfers the Anthropic key through
a structured Box file call, changes it to root-only, and the runner deletes that
transient file after reading it. It is never interpolated into shell command
text, public events or result manifests.

The built-in Box user has sudo, so it is not the scientific agent uid. A trusted
root process prepares the existing release bootstrap, clones DAPPER afresh,
checks the release tag/commit/file hashes, and protects inputs, contracts and
runtime with root ownership/read-only permissions. Claude runs as separate
`reveal-agent` uid 1999 with no supplementary groups and `no-new-privs`, a private
home and a separate writable output directory. The CLI exposes only Read, Glob,
Grep, Write, Edit and the fixed local MCP configuration; no shell, arbitrary web
fetch, subagent or dynamically supplied MCP configuration is available.

A root-owned localhost MCP proxy exposes schema/scope reads for selected graphs,
bounded triple queries generated by the proxy, and pinned draft lint. Raw SPARQL,
SERVICE, arbitrary graph discovery, transcript publication and unselected graphs
are unavailable. Literal selected named graphs are embedded by trusted code;
IRIs and search literals are validated/escaped. Network policy after installation
allows only Anthropic API, the fixed Proto-OKN endpoint and GitHub for the mandatory
fresh release clone. Package source text and upstream guidance cannot expand
this allowlist or authorize additional graphs.

The ledger records attempted calls before network I/O, plus exact request/result
artifacts, SHA-256, byte counts, selected graph, source server version when
available, locators, timestamps and terminal status. Empty, failed, rejected and
interrupted calls are retained. The upstream service may encode zero rows inside
a text content block; the proxy recognizes that without altering original bytes.
Agent-written claims about evidence are never a substitute for this ledger.

## Paragraph contract

`write-cited-paragraph/SKILL.md` defines separate
`reveal.paragraph-input/1` and `reveal.paragraph-output/1` envelopes. Input contains
one accepted account document and authorized exact citation target/revision
pairs. Output contains only authored text segments and citations. External
research tools are disabled. `box_paragraph.validate_paragraph_segments` rejects
unknown versions, additional fields, invalid revisions, unavailable/duplicate
citations and outputs with no accepted Claim citation. `assemble_paragraph`
verifies the locked release then calls its `assemble_cited_text`; backend graph,
registry, attribution, minting and scientific-faithfulness checks remain required.

## Reproduction

Install the normal backend dependencies plus
`pip install -r services/backend/agent-runtime/box-requirements.txt` and
`python-dotenv` for the standalone consumer. Configure ignored environment values
`UPSTASH_BOX_API_KEY` and `ANTHROPIC_API_KEY`; optional `REVEAL_CLAUDE_MODEL` defaults
to `claude-sonnet-4-6`. Claude Code is pinned to `2.1.282`; published Python SDK is
`upstash-box==0.3.0`. Upstream GitHub main reported unreleased 0.3.1 at inspection;
PyPI rejected that version, so the install uses the actual published version.

```sh
PYTHONPATH=services/backend/src python -m unittest discover -s services/backend/tests -p test_box_execution.py -v
python scripts/smoke_box_mcp.py --output .runtime/mcp-probe
python scripts/run_box_agent.py --env-file .env \
  --input data/evidence-packages/cad-builder-v1/evidence-package.json \
  --output .runtime/research-attempt --graph biomarkerkg --graph prokn \
  --budget 3 --timeout 1200 --turns 55
```

`--resume` uses the saved `remote-handle.json`; do not start another paid run to
recover a transient disconnect. Creating `OUTPUT/cancel` requests cancellation.
The captured CAD package uses real public CFDE/DisMech data; its package readiness
requires separate trusted dispatch/runtime/authorization checks. UI illustrative
KG claims are never included as scientific evidence.
