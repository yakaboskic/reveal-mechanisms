# Superseded evidence-profile draft

The graph-path proposal has been withdrawn. No typed path object or EvidenceItem extension is part of the design.

The working design is now maintained in these two documents:

1. [How the agent constructs a ScientificAccount](scientific-account-construction.md): selected gap, one or more scoped propositions and claims, reusable evidence, and the account's final synthesis.
2. [PIGEAN/EAGGL claim templates](pigean-claim-model.md): biological propositions assessed using gene–factor, gene-set–factor, gene–trait and gene-set–trait evidence.

This file remains only to preserve earlier document links. Use the existing DAPPER Claim, Proposition, ClaimScore, EvidenceItem and ScientificAccount fields described in those documents.
